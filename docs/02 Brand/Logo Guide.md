# Logo Guide

> [!warning] Never redraw, recolor, stretch, rotate, add effects to, or rebuild the logo from text. Use the master files in `brand/logo/`.

## Variants
| Variant | File | Use when |
|---|---|---|
| Primary (mark + wordmark, horizontal) | `brand/logo/tallyn-primary.svg` | Default everywhere |
| Stacked | `brand/logo/tallyn-stacked.svg` | Square-ish spaces |
| Mark only | `brand/logo/tallyn-mark.svg` | App icon, favicon, avatars |
| Wordmark only | `brand/logo/tallyn-wordmark.svg` | When the mark is already nearby |
| Mono light / dark | `brand/logo/tallyn-mono-*.svg` | One-color print, photos |

## Clear space
Keep clear space equal to **X** on every side, where X = height of the mark's ___.

## Minimum size
| Variant | Digital | Print |
|---|---|---|
| Primary | 96 px wide | 25 mm |
| Mark | 16 px | 6 mm |

## Color usage
| Background | Logo color |
|---|---|
| Light | Primary / full color |
| Dark | Reversed (white) |
| Photo | Mono, on a calm area only |

## Misuse
- Don't stretch or skew it
- Don't change its colors
- Don't add shadows, outlines or gradients
- Don't place it on busy backgrounds
- Don't rearrange the mark and wordmark
- Don't put it in a container shape unless that's an approved variant

## Files and export
- Master: SVG. Export PNG at 1x/2x/3x for apps and social.
- Favicon set: 16, 32, 180 (apple-touch), 512.
