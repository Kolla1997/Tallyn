# 0001 — Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-08

## Context
Decisions are made in chats, calls and code reviews, and the reasoning gets lost.

## Decision
We record significant technical decisions as ADRs in `docs/04 Tech/ADR/`, using [[ADR|the ADR template]]. Accepted ADRs are never edited. A later ADR supersedes them instead.

## Consequences
New contributors (and Claude) can see why things are the way they are. Writing one takes about 10 minutes per decision.
