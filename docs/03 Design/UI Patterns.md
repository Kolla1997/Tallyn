# UI Patterns

## Empty states
Icon + one-line explanation + primary action.

## Loading
Skeletons for content, spinners only for actions under 2 s.

## Forms
Labels above fields, inline validation on blur, errors in `--color-danger` with text (not color alone).

## Accessibility baseline
- Keyboard reachable, visible focus ring
- Touch targets ≥ 44 px
- Respect `prefers-reduced-motion` and `prefers-color-scheme`
